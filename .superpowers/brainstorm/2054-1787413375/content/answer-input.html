How should the user answer?

In QuickMaths you typed numbers on a keypad. Ear training answers are note names, interval names, chord qualities — so the input is different. Two natural approaches (plus a hybrid). Click the one that feels right.

A

Multiple-choice buttons

A grid of answer choices. For pitch: 12 note buttons (C, C♯, D…). For intervals: named buttons (m2, M2, m3, M3, P4…). For chords: quality buttons (Major, Minor, Dim, Aug, maj7…). For scales: scale-name buttons. Fast, consistent across every drill, works great on a phone with one thumb.

B

On-screen piano keyboard

Tap the note you heard on a piano. Authentic and intuitive for pitch — but it breaks down for intervals/chords/scales, where the answer is a name ("minor 3rd", "dominant 7th"), not a key. A keyboard can't cleanly express "what chord quality was that?"

C

Hybrid (recommended)

Piano keyboard for the pitch drill (tap the note you heard), and multiple-choice buttons for intervals, chords, and scales (pick the correct name). Each drill gets the input that fits its answer type. Slightly more UI to build, but the most natural experience — and the piano doubles as a "replay / explore" aid on the pitch screen.
